# Code provenance

`current_artefact/src/` contains the dissertation-era VGG/Slot-CEM code needed
to load the current spatial foundation. `upstream_cem/` is the preserved CEM
reference implementation used for protocol comparison. New DDP code belongs in
`src/publication_cem/`; these archived files should not be edited in place.

The archive deliberately excludes historical reports, slides, logs, datasets,
and unrelated experimental branches.
